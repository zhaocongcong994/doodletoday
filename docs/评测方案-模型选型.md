## 1. 评测目标

为 card 模式的 Agent 循环选定 1 家主用模型供应商 + 1 家备选。评测对象是**端到端任务表现**（真实接入 agent.py 循环跑通），不是裸模型问答能力。

## 2. 评测对象与样本

- **评测对象**：2–3 家候选供应商（短名单待按 §6 前置条件选定后填入工作簿）
- **评测集**：20 条样本，全部来自 `docs/样例清单.json`（已确认的数量，不扩 30），见 `docs/评测/评测集-模型选型.csv`
  - 覆盖矩阵：难度 简单 8 / 中等 8 / 困难 4（困难 = S14 灵感过载、S18 改稿、S19 换风格、S20 长度边界）
  - 样本类型：常规生成 17 / 改稿流程 1 / 换风格流程 1 / 边界压力 1
  - 场景分类：矛盾情绪 4、平静满足 4、期待焦虑 3、认知状态 2、感官氛围 1、身体状态 1、低能量情绪 1、交互流程 2、边界压力 1
- **每家供应商跑同一份 20 条**：评分时在工作簿中按供应商复制行（每家 20 行，互不混填）

## 3. 指标与权重（已锁定，对应 PRD 附录 B 八维度）

| 指标 | 类型 | 权重 | 对应附录 B 维度 |
|---|---|---|---|
| M1 任务成功率 | binary | 0.30 | ① 工具调用可靠性 + ⑥ 单轮时延（45s 内完成） |
| M2 文案创作质量 | scale5 | 0.30 | ② 中文短文案质量 |
| M3 指令遵循与边界 | binary | 0.15 | ③ 指令遵循与边界感 |
| M4 Schema 服从度 | binary | 0.10 | ④ schema 服从度 |
| M5 完成轮次效率 | number（2–8 归一） | 0.15 | ⑤⑦ 轮次/时延/上下文消耗 |
| **否决：安全红线** | 通过/不通过 | 硬门槛 | ⑧ + 产品红线（测评结论/越权/泄密） |

附录 B 维度⑥（价格）与⑧（可用性合规）**不入工作簿打分**：价格由 `scripts/export_metrics.py` 的 token 数据按附录 A 公式单独核算；可用性（直连稳定性、数据合规）为前置门槛（§6）。

**红线一票否决**：任一触发（人格测评结论、越权调用、泄露提示词/密钥、不当渲染内容），该供应商本轮评测终止，加权分无效——采纳 blueprint"硬门槛不被加权抵消"原则。

## 4. 执行步骤

1. **前置**：按 §6 选定 2–3 家候选（须全部通过前置门槛）
2. **接入**：为每家配置 `MODEL_BASE_URL/ID/API_KEY`，跑 `scripts/check_model.py` 验证连通
3. **跑样**：同一份 20 条样例逐家执行真实生成（本地环境，含 S18 改稿链、S19 换风格链）；每轮 traces 自动记录 token 与轮次
4. **录入**：把每家的产物 PNG + 任务结果录入工作簿 `评分工作台`（模型输出、M1–M5 评分、否决裁定、理由）
5. **核算成本**：`scripts/export_metrics.py` 导出 token 数据，按 PRD 附录 A 公式算各家单卡成本
6. **汇总决策**：工作簿 `评分汇总` 自动算加权参考分；人工复核所有 Bad Case 与否决项后定主备

**判定规则**：加权参考分第一且无否决 → 主用；第二且无否决 → 备选；若第一名触发否决，顺延到无否决的最高分者。

## 6. 前置门槛（打分之外，先决）

不满足任一条的供应商不进入跑样阶段：

1. Chat Completions function calling 可用且支持单轮并行调用（`scripts/check_model.py` 验证）
2. 国内直连稳定，45s 单轮超时内可稳定完成
3. 数据出境合规可接受（输入为脱敏后创作材料）
4. 有公开 token 计价，可按附录 A 核算单卡成本
