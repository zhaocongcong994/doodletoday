# 开发计划与验收

1. 档案：需求、五要素、最小组件、七层架构、契约、边界。
2. 骨架：React + FastAPI + 独立 Node 渲染；真实模型工具调用适配；未配置明确不可用。
3. 硬化：会话隔离、严格校验、限额、超时重试、持久任务、删除清理、日志用量。
4. 验证：核心循环、非法工具、参数错误、模型超时、最大轮次、渲染失败、跨用户、脱敏、偏好、文件导出。
5. 真实验收：20 组场景至少 18 组可导出；人工修正允许，杜撰事实不允许。真实模型/OCR与用户体验不得用测试替身的结果冒充。
6. 体验对比：5–10 人记录完成率、修改次数、导出率、再次使用意愿，再决定投入重点。

边界场景：矛盾状态、空输入、超长中文、局部改稿、偏好清除、中文字体；模糊/旋转票根、纯照片、重复素材、日期冲突、跳过、纠正、10 张；越权、注入、删除、重启。

第二轮：rembg 自动抠图；实际部署与可用性完善；邀请机制强化与跨浏览器身份恢复；成本仪表盘。真实试用指标模板见 trial.csv。
