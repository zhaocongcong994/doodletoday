## 0. 一句话定位

DoodleToday 是一个受邀请制约束的轻量创作 Agent：用户给 3 个今日状态（+可选经历），Agent 创作并渲染一张 1080×1440 人格卡 PNG，支持反馈改稿与直接改文案，明确不是科学人格测评。

**本次迭代规划回答的问题**：从"内测 MVP 已完成、真实验收未做"的当前态，走向什么？

## 附录 A · 单卡成本评估方法

traces 已按轮记录 prompt_tokens / completion_tokens（`agent.py`），单卡成本可精确核算：

```
单卡模型成本 = Σ_每轮 (prompt_tokens × 输入单价 + completion_tokens × 输出单价)
单卡总成本  = 单卡模型成本 + 渲染摊销（本地 Satori，按机器时长摊薄，近似常数）
日成本上限  = 20 × 单卡总成本（改稿与自定义风格渲染同口径，均为完整任务）
```

执行步骤：P0 接入候选供应商 → 跑 20 场景基准 → `scripts/export_metrics.py` 导出 token 数据 → 乘各家单价横向比较 → 回填预算上限与配额合理性结论。

**已回填（2026-09-17 实测，20 场景 × 22 任务）**：

| 供应商 | prompt tokens | completion tokens | 单卡模型成本 | 日成本上限（20 次） |
|---|---|---|---|---|
| DeepSeek（deepseek-chat） | 57,877 | 3,849 | ≈¥0.0037（空闲）/ ¥0.0073（高峰） | ≈¥0.07–0.15 |
| MiniMax-M2.7 | 55,564 | 11,128 | ≈$0.0015（≈¥0.011） | ≈¥0.22 |

结论：两家成本都低到不构成决策约束（<¥0.25/天），选型以质量与可靠性为准（见评测报告）。价格来源：DeepSeek [官方定价页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)、MiniMax [官方定价](https://platform.minimax.cn/docs/guides/pricing-paygo)。

## 附录 B · 模型供应商评估维度

| 维度 | 具体考察点 |
|---|---|
| 工具调用可靠性 | Chat Completions function calling 稳定性；是否支持单轮并行调用（循环内 ≤8 个） |
| 中文短文案质量 | 24 字标题 / 70 字副标题 / 12 字标签的趣味性与辨识度（20 场景人工打分） |
| 指令遵循与边界感 | 不输出人格测评结论、不编造风格 ID、成功渲染前不报完成 |
| schema 服从度 | Pydantic `extra='forbid'` 下不产多余字段、类型/长度合规（影响轮次消耗） |
| 单轮时延 | 45s timeout 内稳定完成 |
| 价格 | 输入/输出 token 单价（结合附录 A） |
| 上下文余量 | 改稿链 + 风格知识注入后仍留有余量 |
| 可用性与合规 | 国内直连稳定性、数据出境合规（脱敏后数据） |

评估方法：同一批 20 场景样例跑 2–3 家候选，对比成功率 / 平均轮次 / 文案质量分 / 单卡成本，选综合最优并留一家备选。
